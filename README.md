# Credit Card Fraud Detection — MLP + Autoencoder Ensemble

A fraud detection system for anonymized credit card transactions, combining a
supervised classifier and an unsupervised anomaly detector through a stacked
ensemble.

## Models Used

- **MLP (Multi-Layer Perceptron)** — supervised classifier trained on
  SMOTE-balanced data. Outputs a fraud probability.
- **Autoencoder** — trained only on normal (non-fraud) transactions. Flags
  transactions with a high reconstruction error as anomalies.
- **Logistic Regression meta-model** — combines the MLP probability and the
  Autoencoder's reconstruction error (stacking) into one final fraud score.

## Preprocessing Summary

- `Time` was converted into a cyclic `Hour` feature (`(Time // 3600) % 24`)
  and the raw `Time` column was dropped.
- `Amount` was log-transformed (`log1p`) to reduce the influence of extreme
  values.
- Final feature set (30 columns, exact order saved in `feature_columns.pkl`):
  `V1 … V28, Amount, Hour`.
- The MLP uses a `StandardScaler` fit on the full (imbalanced) training set.
- The Autoencoder uses a separate `RobustScaler` fit only on normal
  transactions.
- Class imbalance for the MLP was handled with SMOTE (training data only).

## Ensemble Idea

Both models are evaluated on the same held-out transactions. Their two
outputs — MLP probability and Autoencoder reconstruction error — are scaled
and fed into a Logistic Regression meta-model (stacking), which learns how
much weight to give each signal. The meta-model's output is thresholded
(F2-optimized) to produce the final FRAUD / LEGITIMATE decision.

## How to Run

1. Install dependencies:

   ```
   pip install -r requirements.txt
   ```

2. Make sure all the artifact files listed above are in the same folder as
   `app.py` (generated by running the notebook end-to-end).

3. Launch the app:

   ```
   streamlit run app.py
   ```

The app never loads `creditcard.csv` — it only uses the saved model and
preprocessing artifacts for inference.
